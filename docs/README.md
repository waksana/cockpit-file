# 设计文档

当前保存的是已讨论的产品边界与待实现的前端契约，不是可调用 API 或已实现功能。
文中的插口、事件、函数名为示意；实际导出名和版本号在接入时确定。

| 文档 | 负责的主题 |
| --- | --- |
| [前端接入契约](frontend-contract.md) | 组件和页面注册、输入事件、草稿字段、发送阻止、渲染与宿主分工。 |
| [文件引用与地址](file-references.md) | 用户原生附件、助手 Markdown、消息身份、托管 path 与 URL 映射、版本语义。 |
| [前端验收清单](acceptance.md) | 独立模块接入、上传交互、发送、渲染、隔离失败与回归边界。 |

## 文档边界

- 本仓库维护文件模块的产品行为和它所需的通用宿主能力。
- Cockpit 真正发布公共接口后，宿主 ABI 的唯一权威应是其公开契约；
  本仓库引用对应版本，不另维护一套不兼容的接口。
- 模块后端已选择主进程 `import`、首版冷加载、前后端同包；这些尚未实现。
- 本轮聚焦前端，不提前引入通用任务编排、展示资源订阅图或第二份聊天库。
- 文件库的容量限制、预览支持矩阵、文件删除政策仍需进一步明确。
